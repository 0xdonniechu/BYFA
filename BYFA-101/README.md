# BYFA-101 — Build Your First Agent

Audience: non-tech, newbies.
Outcome: build 1 end-to-end agent for your real work.
Motto: simple, effective, practical.

Total: 5 modules, 12 sessions, ~4.5-5 hours + exercises.

## Modules
- M1: Spot the job + agent thinking (2 sessions)
  - [S01 What an agent is](s01-what-is-an-agent/README.md)
  - [S02 Lock in 1 real job](s02-lock-in-one-job/README.md)
- M2: No-code tooling (2 sessions)
  - [S03 Account setup + playground](s03-account-setup-playground/README.md)
  - [S04 Prompt, tool, memory](s04-prompt-tool-memory/README.md)
- M3: Build your first agent (4 sessions)
  - [S05 Agent frame](s05-agent-frame/README.md)
  - [S06 Connect your real data](s06-connect-real-data/README.md)
  - [S07 Add 1 tool](s07-add-one-tool/README.md)
  - [S08 First end-to-end run](s08-first-end-to-end-run/README.md)
- M4: Evaluate + fix (2 sessions)
  - [S09 Test 5 real cases](s09-test-five-real-cases/README.md)
  - [S10 Fix 3 common failures](s10-fix-three-failures/README.md)
- M5: Ship + use daily (2 sessions)
  - [S11 Publish / share + privacy](s11-publish-and-privacy/README.md)
  - [S12 Weekly plan + showcase](s12-weekly-plan-and-showcase/README.md)

Each session: 1 short video + 1 guide page (both in the course LMS) + 1 15-minute exercise (this folder).

Details: `../docs/brainstorm-BYFA-101.md`.
