# my-agent

This folder is YOUR agent, for one real job of yours. It grows across the course:

| File | Created in |
|---|---|
| `task-list.md` | S1 |
| `brief.md` | S2 |
| `three-parts.md` | S4 |
| `CLAUDE.md` (the agent's instructions) | S5, improved in S6, S7, S10 |
| `data/` (your data, with private details masked) | S6 |
| `tools.md` | S7 |
| `runs/run-01.md` | S8 |
| `tests/cases.md` | S9, S10 |
| `share/` (the clean copy you hand to someone) | S11 |
| `weekly-plan.md`, `showcase.md` | S12 |

Git tracks nothing in this folder except this README, so your work is not uploaded if you
push the repo. Claude reads these files to help you, and what it reads is sent to the AI
provider, so mask private details before you put them in.

To use your agent, open this folder in Claude Code and give it work.
