# Brainstorm BYFA-101

Goal: non-tech learners build a work agent themselves.
Motto: simple, effective, practical.

## Proposal: 5 modules / 12 sessions / ~4.5-5h

### M1 — Spot the job + agent thinking (2 x 20')
- S1: What an agent is, when you need one / don't
- S2: Lock in 1 real job of yours (output: 1-page brief)

### M2 — No-code tooling (2 x 25')
- S3: Account setup + playground
- S4: Prompt, tool, memory in plain terms + trial run

### M3 — Build your first agent (4 x 25-30')
- S5: Agent frame: input -> process -> output
- S6: Connect your real data
- S7: Add 1 tool (search / file / spreadsheet)
- S8: First end-to-end run

### M4 — Evaluate + fix (2 x 20')
- S9: Test 5 real cases
- S10: Fix 3 common failures (off-topic, missing context, bad output)

### M5 — Ship + use daily (2 x 20')
- S11: Publish / share + privacy
- S12: Weekly usage plan + showcase

Each session: 1 short video + 1 guide page + 1 15-min exercise.
