# S11 - Publish / share + privacy

Module 5: Ship + use daily - video about 20 min

**Output:** A way to hand the agent to someone else, with a privacy check done.

## Exercise (15 min)
1. List what is inside my-agent/ that must not be shared (data, names, keys).
2. Copy only the files you are happy to share (usually CLAUDE.md and tools.md) into a new folder my-agent/share/. Leave out data/, runs/, tests/ and anything with real names.
3. Add a 3-line README.md to share/: what the agent does, what input it expects, one made-up example. The other person brings their own data in the same shape.
4. Hand it to one real person and watch them try it once.
