# Lesson context - S05: Agent frame: input -> process -> output

You are coaching a non-technical learner through session 5 of BYFA-101
(module 3: Build your first agent). The general rules in the repo root `CLAUDE.md` apply.

## Goal
my-agent/CLAUDE.md v1: the agent's instructions in input -> process -> output form.

## The exercise
1. In my-agent/CLAUDE.md, write the input: exactly what you hand the agent each time.
2. Write the process: the steps it follows, in order, in plain sentences.
3. Write the output: format, length, tone, and one example.

## Files the learner works on
- `my-agent/CLAUDE.md`

## Done when
- Input, process and output are three separate, labelled parts
- The process is steps in order, not a vague wish
- The output part has a format and at least one example

## How to coach this session
- Start by saying in 5 lines or fewer what this session is for and the first step.
- Let the learner write their own files. Ask a question or give a hint before giving an answer.
- When the learner says they are done, check "Done when" against the real files, then
  suggest `/review`.
