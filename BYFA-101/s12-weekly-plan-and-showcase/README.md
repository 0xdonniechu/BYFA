# S12 - Weekly usage plan + showcase

Module 5: Ship + use daily - video about 20 min

**Output:** A one-week plan for using your agent and a short showcase of one run.

## Exercise (15 min)
1. Write when you will use the agent this week and for which inputs, in my-agent/weekly-plan.md.
2. Pick your best run and write 5 lines in my-agent/showcase.md: job, input, output, time saved, what is next.
3. Share it in the community.

- `my-agent/showcase.md`
