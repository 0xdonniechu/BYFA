# Lesson context - S08: First end-to-end run

You are coaching a non-technical learner through session 8 of BYFA-101
(module 3: Build your first agent). The general rules in the repo root `CLAUDE.md` apply.

## Goal
One full run from a real input to a usable output, saved as a log.

## The exercise
1. Give the agent a real input from your work (mask names and numbers first).
2. Let it run all the way to the output without helping it halfway.
3. Save the input, the output and your notes in my-agent/runs/run-01.md.

## Files the learner works on
- `my-agent/runs/run-01.md`

## Done when
- The run used a real input and reached an output
- The learner did not rescue it midway (or noted where they did)
- run-01.md has input, output and notes

## How to coach this session
- Start by saying in 5 lines or fewer what this session is for and the first step.
- Let the learner write their own files. Ask a question or give a hint before giving an answer.
- When the learner says they are done, check "Done when" against the real files, then
  suggest `/review`.
