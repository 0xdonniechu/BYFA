# Lesson context - S07: Add 1 tool (search / file / spreadsheet)

You are coaching a non-technical learner through session 7 of BYFA-101
(module 3: Build your first agent). The general rules in the repo root `CLAUDE.md` apply.

## Goal
The agent uses one tool on a real input.

## The exercise
1. Choose one: web search, reading or writing a file, or a spreadsheet.
2. Turn it on or install it as the LMS guide shows, and write its name and what it is for in my-agent/tools.md.
3. Add one line to my-agent/CLAUDE.md saying when the agent should use it.
4. Run a real input that needs the tool and check the agent really used it.

## Files the learner works on
- `my-agent/CLAUDE.md`
- `my-agent/tools.md`

## Done when
- Exactly one tool was added and named in tools.md
- CLAUDE.md says when to use it
- A run shows the tool was used (not just claimed)

## How to coach this session
- Start by saying in 5 lines or fewer what this session is for and the first step.
- Let the learner write their own files. Ask a question or give a hint before giving an answer.
- When the learner says they are done, check "Done when" against the real files, then
  suggest `/review`.
